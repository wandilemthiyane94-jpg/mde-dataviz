# SA flood coverage: the article dataset

Media-framing coding of **199 article URLs** (the coders report 199 articles read) across **53 deadly South African flood events, 2016-2026**.

| File | Contents |
|---|---|
| `articles.csv` | One row per article: event, date, provinces, deaths, URL, outlet |
| `event_coding.csv` | One row per event: patterns P1-P6 (true / false / not_determinable) with verbatim evidence + URL, and counts of officials / residents / others quoted |
| `pattern_summary.csv` | Totals per pattern |
| `articles_by_outlet.csv` | Article count per news outlet |
| `media_patterns_coded.json` | The full original coding, including coder notes and method |

**Patterns:**
- P1: death toll reported as rising, never final
- P2: "informal settlement" named as the cause
- P3: presidential visit (P3b: Premier / Minister / MEC)
- P4: officials quoted over residents
- P5: climate change framing
- P6: pre-event warning mentioned at all

**Method:** 53 events from deadly_events_kzn.json (32) + deadly_events_rest.json (21), coded by 7 parallel coders using coded_parts/PROTOCOL.txt. 199 pages read in total (1-8 per event), news prioritised over aggregators. Values reflect the coverage read: false = not found in that coverage. Evidence snippets come from WebFetch extractions; coders flagged in notes where exact verbatim wording could not be confirmed. News24 and IOL frequently returned 403, ReliefWeb always 403, so some events rest on aggregators/SAnews. Size split used in notes: 'big' = 16 events with roughly >=10 deaths; 'small' = 37 others. Caveat: 2024-07-western-cape-storms has no flood deaths per its own sources (GroundUp) and probably should not be in a deadly-events set.

Values reflect the articles read: "false" means not found in that coverage. Generated by `methods/scripts/export_articles.ps1`.
