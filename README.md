# Moved Into the Water

Interactive map of temporary flood-relocation sites in Durban (eThekwini). MDE Project 2.

## Open it
Double-click `index.html`. It needs the internet only for the satellite view and the fonts.

## Files
- `index.html`: layout, styling and map code (about 40 KB, safe to edit)
- `data/sites.js`: the facts for each site, the journeys and the flood events. Edit this to change text, add photos or videos.
- `data/map-data.js`: rivers, flood line and coast. Generated; do not edit by hand.
- `assets/`: relief image, water record images, flood sound.

## Put it online (GitHub Pages)
Settings > Pages > Deploy from a branch > `main` and `/ (root)`. The map appears at `https://<user>.github.io/<repo>/`.

## Data sources
Flood line and rivers: eThekwini Municipality. Water record: JRC Global Surface Water (30 m). Heights: Copernicus DEM (30 m) and eThekwini 2 m contours. Imagery: Esri World Imagery. Site facts: news reports listed per site.
